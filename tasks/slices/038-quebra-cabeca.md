# Slice 038 - Quebra-cabeça (cognição)

## Status

done

## Objetivo de negocio

Incluir um jogo cognitivo de quebra-cabeça no catálogo: a criança arrasta peças para completar a imagem, com progressão de dificuldade.

## Entrega verificavel

- Conteúdo `jigsaw` no catálogo (`category: memoria`)
- 15 rodadas: 5 fácil 3×3, 5 médio 4×4, 5 difícil 5×5
- 15 cenas de arte distintas (`round_1`…`round_15`)
- Setup com escolha de dificuldade (web + mobile)
- Compatibilidade de runtime com rodadas legadas sem `difficulty`
- Prévia web e execução mobile

## Fora de escopo

- Distratores além das peças da rodada
- Editor visual de puzzles
